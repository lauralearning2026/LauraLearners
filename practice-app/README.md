# Algebra II Practice app

A separate app for TCAP Algebra II end-of-course practice. It lives in this folder and deploys as its own Vercel
project, so it never touches the LauraLearning portfolio site.

- **Students** sign in with a code from their teacher, practice sets of 10, complete assigned sets, and see their own progress.
- **The teacher** creates classes and codes, sees accuracy by standard, gets pattern flags, and approves intervention sets.
- **Administrators** sign in with an admin code and see class-level results and the question bank. They never see student labels or individual answers.

No names, emails or passwords are stored. Students are identified only by the label the teacher gives each code (for example `P2-07`).
Answer keys stay on the server; students' browsers never receive them.

## One-time setup in Vercel

1. **New project.** In Vercel, choose *Add New → Project*, import the `LauraLearners` repository, and set **Root Directory** to `practice-app`. Deploy.
2. **Database.** In the new project, open *Storage → Create Database → Neon (Postgres)* and connect it to the project. This adds `DATABASE_URL` automatically. The tables are created on first use.
3. **Setup key.** In *Settings → Environment Variables*, add `SETUP_KEY` with a long private phrase only you know. Optionally add `SESSION_SECRET` (any long random text).
4. **Redeploy** so the new settings take effect.
5. **Create your teacher code.** Open the app, choose *First-time setup for the teacher*, and enter the setup key. Write the teacher code down. Setup works only once.
6. **Domain (optional).** In *Settings → Domains*, add `practice.lauralearning.org` and follow Vercel's DNS instructions.

## Using it

- *Classes & codes*: add a class, make codes, print code cards, turn codes off, replace lost codes, or delete a student and their answers.
- *Delete student data* removes every student code, answer and intervention at the end of the pilot.
- Students and staff can install it from the browser (*Install app*, or *Add to Home Screen* on phones).
- In Teams, add a *Website* tab to the class team with the app's address.

## Question bank

`lib/bank-data.ts` is generated by `tools/algebra2/build.py` from the same bank as the website practice page. Do not edit it by hand.
Question IDs are locked in `tools/algebra2/ids.json`, so saved answers always point to the same question.
